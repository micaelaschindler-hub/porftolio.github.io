¿Quién soy?

Soy Micaela Schindler, diseñadora gráfica egresada de la Tecnicatura en Diseño Gráfico. Vivo en Córdoba, Argentina. Me interesa el diseño editorial, la tipografía y la comunicación visual.

Estoy aprendiendo desarrollo web — HTML y CSS — para poder llevar mis ideas de diseño directamente al entorno digital, sin depender de otras personas para la parte técnica.

Formación

→ Tecnicatura en Diseño Gráfico — egresada

→ Laboratorio Digital — HTML, CSS, optimización web

→ freeCodeCamp — Responsive Web Design (en curso)

→ Audiovisual — producción de video publicitario

Herramientas que uso

En diseño trabajo con Adobe Illustrator, Photoshop y Premiere Pro. Para la web estoy aprendiendo HTML, CSS y usando Visual Studio Code como editor de código.

Mis proyectos los subí a GitHub para publicarlos y tenerlos versionados.

Un proyecto destacado

Realicé un video publicitario para zapatillas Ace Strider en la materia Audiovisual (2024). Usé una paleta de rosas, fucsia y morado con estética de degradado — podés verlo en el blog M_ICA.
